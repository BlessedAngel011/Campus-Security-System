# V9 changes

- Keeps UFH email as institutional identity.
- Adds a separate personal Gmail address for OTP verification and password recovery.
- New student/staff registrations require a unique @gmail.com personal email.
- OTP and password-reset codes are delivered to the personal Gmail address.
- Administrator creation also collects a personal Gmail and sends admin sign-in OTPs there.
- Existing legacy accounts without a personal email retain UFH-email OTP fallback until updated.
- Password minimum remains 8 characters.
- V8 non-blocking SOS vibration behavior is preserved.
