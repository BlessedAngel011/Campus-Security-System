Campus Safety Made Simple

The system connects students with campus security and provides tools for incident reporting, monitoring and emergency response.

Report Incidents

Students can securely submit details about theft, assault, harassment, vandalism, suspicious activity and other safety concerns.

Track Reports

Students can monitor submitted incidents as security moves them from Pending to In Progress and finally Resolved.

Priority Response

Priority levels help campus security identify urgent situations and respond appropriately.

One System. Different Roles.

Each user is directed to the tools they need after signing in.

Students

Report incidents, track reports, access emergency contacts and use Campus SOS.

Security Officers

View incidents, identify priority cases, search reports and update incident status.

Administrators

Create accounts and manage system users, roles, passwords and account access.
